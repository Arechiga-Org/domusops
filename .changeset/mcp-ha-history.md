Adds `ha_history`, a read-only tool that returns how entities changed over a time window: for each one the state it had at the start of the window, then every recorded change with its time, its state and the attributes that changed, so an agent can tell when an attribute changed and to what without falling back to the raw API. `entities` and `exclude` take the same IDs and patterns as the other tools; `start` and `end` are read as `ha_logbook_query` reads them, with a default of the last 24 hours and a maximum of 10 days; `attributes` keeps only the attributes named and lists only the changes in which one of them, or the state, changed; `significant_only` keeps only the changes the instance considers significant. `detail=summary` gives the number of changes per domain, and per entity when `entities` is given. Times are in the instance's local time, to the second. A result above 100,000 bytes (`DOMUSOPS_HISTORY_MAX_BYTES`) is refused with the number of entities and changes. The instance's history records no cause; `ha_logbook_query` over the same window gives it. The snapshot's redaction applies; names stay visible. The tool needs the `history` integration, and `ha_ping` lists it; the other tools' outputs do not change.
