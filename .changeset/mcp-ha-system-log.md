Adds `ha_system_log`, a read-only tool that returns the errors and warnings the instance has recorded in its system log since it last started: for each entry its level, logger, the integration it belongs to (custom integrations marked), its source file and line, how many times it occurred, its first and last occurrence, its distinct messages and its full exception traceback, so an agent can find why an integration stopped working without falling back to the raw API or asking for pasted logs. An entry's integration comes from its logger or, for a library's logger, from its source file. `integrations` and `exclude` take integration domains and `*` patterns; `level` keeps entries at that level or above; `start` keeps entries whose last occurrence is at or after it. `detail=summary` gives the number of entries and occurrences per integration and level. Times are in the instance's local time, to the second. File paths lose the installation, configuration and Python library roots (`{ha}/`, `{config}/`, `{python}/`), and the text redaction of the other tools applies to messages and tracebacks. A result above 100,000 bytes (`DOMUSOPS_SYSTEM_LOG_MAX_BYTES`) is refused with the number of entries. The tool needs the `system_log` integration, and `ha_ping` lists it; the other tools' outputs do not change.
